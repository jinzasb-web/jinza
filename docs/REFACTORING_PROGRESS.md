## ⚠️ 当前限制 / Current Limitations

### 演示环境限制
1. **数据存储**：LocalStorage 容量有限（~5-10 MB）
2. **多用户**：不支持真正的多用户并发
3. **数据备份**：需要手动导出
4. **e-Invoice**：仅模拟，未真实对接 MyInvois
5. **性能**：适用于小规模交易量

### 生产部署需求
- ✅ 后端 API 与数据库
- ✅ 用户认证系统（OAuth / JWT）
- ✅ 云端部署与自动备份
- ✅ SSL 加密与安全防护
- ✅ 性能监控与日志系统
